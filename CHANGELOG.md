# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to Semantic Versioning.

## [1.0.0.0] - 2026-07-02

### Added
- Multi-tenant super admin dashboard for subscription and billing management.
- Quick renewal, suspension, unsuspension, and audit logging workflows for tenant accounts.
- System metrics overview page listing global company status, user, and branch counts.
- Subscription audit log viewer for tracking all billing and account status changes across tenants.
- Role-based permissions matrix restricting admin features to authorized SUPER_ADMIN users.
- Integration tests validating statistics and audit endpoint behaviors.
