# L1 Destek Karar Agaci

## Yazici Sorunu
1. Cihaz acik mi?
2. Baglanti (LAN/USB) dogru mu?
3. Test fisi sonucu?
4. Hata devam ederse L2 eskalasyon.

## Cekmece Sorunu
1. Pulse ve port ayari dogru mu?
2. Cekmece test adimi sonucu?
3. Donanim kablo kontrolu.
4. Devam ederse L2.

## Sync Sorunu
1. Internet var mi?
2. Kuyruk adedi ve son sync zamani?
3. Manuel sync dene.
4. `FAILED` kayit varsa logla ve L2.

## Lisans Blok
1. Cihaz saati dogru mu?
2. Online login ile yeniden dogrula.
3. Paket suresi/suspend durumu kontrolu.
4. Cozulmezse merkez destek.
